# Tuesday Dream Machine

A Raspberry Pi ambient sound machine and night light for Tuesday's room. It plays
four looping painted scenes (Ocean & Lighthouse, Rainy Forest, Space, Campfire)
with matching ambient sound, dims itself with the room, and can be controlled
from Apple Home / Siri, Google Home, a phone, or a parent-locked touchscreen.
